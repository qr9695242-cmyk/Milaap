# Milaap Game Audit

The public game catalog now contains only the real, implemented games:

1. Ludo — full 2/4-player rules and server-authoritative match flow.
2. Chess — legal-move board gameplay with solo AI and match flow.
3. Carrom — board/striker/pocket gameplay with solo and match flow.
4. Archery — target/aim scoring gameplay with solo and match flow.

Non-real/arcade placeholder games have been removed from the public catalog, room menu, home/profile/store links, routes, and game artwork.

The Farm/GreedyFarm mini-game is also removed from the games list so only the four real games are shown.
